# CURRENT PROJECT MISSION

## 1. Current Phase
Архитектурная стабилизация и интеграция всех модулей (Blogs, Posts, Messages, Bots, Profile).

## 2. Priority Focus
1. Доведение системы до "рыночного" качества портфолио.
2. Стабильность системы сообщений и файлового хранилища.
3. Отладка модуля генерации ботов (исправление логики работы с файлами).
4. Подготовка архитектуры к масштабированию и CI/CD.

## 3. What Is NOT Allowed
- Нарушение DDD-слоев (зависимость домена от внешних библиотек).
- Хранение несериализуемых данных в Redux.
- Костыльные решения в FileService или логике сообщений.
- Упрощения, снижающие уровень проекта для рынка труда.

## 4. Strategic Goal
Создать проект, который соответствует уровню Senior-разработчика при оценке кода: чистая архитектура, тестируемость, отсутствие «сервисов-богов».
